# animated-login-page
A modern and responsive Login/Sign-Up interface built using HTML, CSS, and a little JavaScript. It features smooth transitions between login and registration forms, animated backgrounds, and icon-enhanced inputs with floating labels.

✨ Features
🌌 Animated background layers with CSS transforms

🔁 Smooth transition between login and registration forms

🧠 Floating input labels with focus & validation effects

🎨 Custom animation delays using CSS variables (--delay)

🔒 Clean, responsive layout with modern glassmorphism style

📦 Icon support via Boxicons

📁 Tech Stack
HTML5 – semantic structure for forms

CSS3 – transitions, animations, layout, and UI design

JavaScript – simple class toggling logic

Boxicons – icons for input fields
